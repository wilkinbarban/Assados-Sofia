# OpenSpec Folder

This folder contains the active specifications, proposals, technical designs, and task backlogs for the **Sofía (Asados)** project as part of Spec-Driven Development (SDD).

## Directory Structure

- `config.yaml`: Global SDD metadata, stack settings, conventions, and testing capabilities.
- `proposals/`: Change proposals (`.md`).
- `specs/`: Active specifications and requirement deltas (`.md`).
- `designs/`: Technical design docs and architecture proposals (`.md`).
- `tasks/`: Task breakdown and implementation checklists (`.md`).
- `archive/`: Archived changes and histories.
